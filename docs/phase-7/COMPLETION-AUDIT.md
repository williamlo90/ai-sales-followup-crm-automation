The release scope is OpenAI-only for hosted inference, as agreed for Phase 6. Claude/Grok adapters are implemented but not live API-validated. Qwen3 1.7B local inference was tested and rejected on quality; it is not a fallback. Regular customer email sending remains disabled. The frozen synthetic dataset is regression evidence, not a fresh holdout or customer ROI study.

A later, separately scoped [project OAuth acceptance](../evidence/phase-7-outlook-oauth-connected.json) joined the inbound message, AI review, Odoo effect and one self-test Outlook send in the same local run. It supplements this original gate record; the original measurements and release archive remain tied to their recorded snapshots.

The connected path uses one known test deal and automated, separate lab roles. Faults such as 429, response loss and Graph unknown state were injected at explicit boundaries; these are not claims of vendor outages or a live email timeout. Workload percentiles come from small deterministic N without Graph/model latency; the full connected path was not benchmarked at those percentiles. Rollback evidence is component-level plus connected interruption recovery, not an atomic reversal of Graph/Odoo side effects. The Ubuntu lifecycle test restarted only the distro, not Windows or the shared WSL kernel. Docker Desktop's user-distro proxy needed manual recovery after the restart; it is available for the current session through a hidden helper, not installed as permanent startup configuration. Local alert delivery used a loopback receiver, not a human notification channel.

Final regression: `python -m pytest -q` passed 327 tests in 13.10 seconds; `git diff --check` passed. PostgreSQL stayed at or below the 256 MiB cap, owned test containers were stopped, and the three unrelated container IDs were unchanged at final inspection. Phase 8 must document activation, Docker Desktop/Ubuntu reattachment, credential refresh, operator review, backup/restore and the local host-offline behavior before delivery.
